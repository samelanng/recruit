# 基础知识问答

1. 学习率
什么是学习率（Learning Rate）？学习率设置过大或过小分别可能对模型训练产生什么影响？实际训练过程中可以通过哪些方法调整学习率？

- 学习率是一个超参数，决定模型在每次迭代的过程中参数更新的幅度。
- 学习率过大会导致一步跨过最低点，使loss剧烈震荡,甚至发散；太小会导致模型收敛速度太慢，或卡在鞍点或局部最小点。
- 可以手动调节试错；用Adam/Adam这类自适应优化器，能给每个参数单独调整有效步长；使用学习率调度器，比如余弦退火、warmup等。

2. 损失函数
什么是损失函数（Loss Function）？它在模型训练过程中起什么作用？分类任务和回归任务为什么通常会使用不同的损失函数？

- 损失函数是用于计算模型预测值和实际值之间差距的函数；它能提供参数优化目标，指导参数更新的方向，是梯度下降的前提，同时也是作为衡量模型好坏的指标。
- 分类任务的输出是每个类别的概率分布，使用softmax+交叉熵衡量，其值只与预测错误的数量有关；回归任务的输出是连续值，其误差本身具有意义，用MSE等直接度量差距。

3. 过拟合与欠拟合
什么是过拟合（Overfitting）？什么是欠拟合（Underfitting）？它们通常分别有哪些表现？可以通过哪些方法进行改善？

- 过拟合是指在训练集的表现优异但在新数据上表现差；欠拟合是指模型未充分学习到数据中的模式，一般在训练集和验证集上表现都较差。
- 过拟合表现为训练集loss持续下降，验证集loss先降后升，两者之间差距增大。
- 过拟合：数据增强、正则化、早停、交叉验证；欠拟合：增加训练轮数、加深加宽模型、增加有效特征、更换优化器，调整学习率等。

4. 梯度下降
什么是梯度下降（Gradient Descent）？它为什么能够用于优化神经网络参数？Batch Gradient Descent、SGD 和 Mini-batch Gradient Descent 有什么区别？

- 梯度下降是指沿着梯度的反方向更新参数，让损失下降得最快。
- 函数在局部沿梯度反方向下降最快；只要损失函数可导（或几乎处处可导），就能用链式法则算出每个参数的梯度，然后迭代逼近一个极小值。
- Batch GD每次使用全部样本，梯度最为准确、曲线最平滑，但每次迭代都要遍历全量数据。SGD每次使用单个样本，更新极快但噪声大，有助于跳出局部最小点，但收敛曲线容易抖动。Mini-batch GD每次使用一batch的数据，是以上两种的折中方案，能运用矩阵运算在GPU上并行，梯度也比单样本更稳定。

5. 前向传播与反向传播
什么是前向传播（Forward Propagation）和反向传播（Backpropagation）？神经网络为什么需要反向传播才能完成训练？

- 前向传播指输入层通过逐层运算，最终得到输出，并用损失函数计算误差。反向传播是利用链式法则，从损失开始逐层王辉求每个参数的偏导，计算每个参数更新的方向，然后优化器据此更新。
- 参数有几百万个，用数值近似求梯度要对每个参数各做一次前向，代价无法接受。反向传播是反向模式自动微分，一次前向加一次反向就能得到全部参数的梯度，计算量与一次前向传播同阶。

6. 激活函数
为什么神经网络中需要加入非线性激活函数？如果一个多层神经网络中的所有激活函数都被删除，会发生什么？请简单比较 ReLU、Sigmoid 和 Tanh 的特点。

- 激活函数给网络注入非线性，否则多深的网络都等价于一个单层线性模型。
- 线性变换的复合还是线性变换。如果所有激活函数都去掉，例如$$W3(W2(W1x)) = (W3W2W1)x$$，那么三层塌缩成一个矩阵，深度完全失去意义，网络也就无法拟合曲线、无法做非线性分类。

| 激活函数 |输出范围 | 优点 |缺点
|---------|------|------|-----
| ReLU | [0,+∞) | 计算极快、不饱和、缓解梯度消失、有稀疏性 |负半轴梯度为 0，可能出现"Deadly ReLU",此时不更新参数
| Sigmoid | (0,1) | 输出可当概率，曲线平滑 |两端饱和，梯度消失；输出非零中心
| Tanh   | (-1,1)  |零中心，收敛比 Sigmoid好 |两端仍然饱和，深层网络依旧会梯度消失

7. 梯度消失与梯度爆炸
什么是梯度消失（Vanishing Gradient）和梯度爆炸（Exploding Gradient）？它们为什么会影响深层神经网络的训练？有哪些常见的缓解方法？

- 梯度消失指在反向传播过程中， 梯度从输出层向输入层传播时，逐层衰减，最终接近于0，导致靠近输入层的参数几乎无法更新，模型训练陷入停滞。梯度爆炸指反向传播过程中，梯度从输出层向输入层传播时，逐层放大，最终趋于无穷大，导致参数更新幅度过大，模型训练不稳定甚至崩溃。
- 预训练加微调；梯度剪切、权重正则（针对梯度爆炸）；使用不同的激活函数；使用batchnorm；使用残差结构；使用LSTM网络。

8. Epoch、Batch Size 与 Iteration
请解释 Epoch、Batch Size 和 Iteration / Step 分别是什么。Batch Size 的大小会对训练速度、显存占用以及模型训练产生哪些影响？

- Epoch是指把整个训练集完整过一遍；Batch Size是一次前向+反向用多少条样本；Iteration/Step是参数更新一次，处理完一个 batch就是一个step。

| 维度 | Batch 小 | Batch 大 |
| --- | --- | --- |
| 显存占用 | 小 | 近似线性增长（主要是中间激活值），过大直接 OOM |
| 训练速度 | 每步快，但步数多；GPU 并行度低、利用率低 | 每步慢，但并行效率高、总步数少；显存吃紧时反而可能变慢 |
| 模型训练 | 梯度噪声大，有正则化效果，常能找到更平坦的极小点，泛化有时更好 | 梯度更准、曲线更平滑，但容易收敛到尖锐极小点，泛化可能略差 |

9. 优化器
优化器（Optimizer）在神经网络训练中负责什么？请简单比较 SGD 和 Adam 的特点，并说明为什么不同优化器可能得到不同的训练结果。

- 梯度只提供往参数修正方向，优化器决定这一步到底走多大、要不要带惯性、每个参数是否用不同的步长。它把梯度翻译成实际的参数更新量。

| | SGD（含 Momentum） | Adam / AdamW |
| --- | --- | --- |
| 核心思想 | 直接用动量平滑后的梯度，所有参数共用一个学习率 | 一阶动量 + 二阶动量，给每个参数自适应缩放有效步长 |
| 内存 | 只需存梯度和动量，省显存 | 要额外存m 和 v，约多占一倍优化器状态 |
| 收敛速度 | 慢，对学习率很敏感 | 快，对学习率不那么敏感 |
| 适用场景 | 数据充足、追求最终泛化（CNN 分类常用） | 稀疏梯度、Transformer/大模型、快速迭代（NLP 主流） |
| 已知问题 | 学习率难调、病态曲率下震荡 | 正则化处理不当会削弱 weight decay效果（所以有了 AdamW） |

- 不同优化器有不同的更新轨迹，最终落在不同的极小点上，而不同极小点的泛化性能并不相同。另外它们对学习率、对梯度噪声、对曲率各向异性的反应不同。

10.  训练集、验证集与测试集
训练集（Training Set）、验证集（Validation Set）和测试集（Test Set）分别有什么作用？什么是数据泄漏（Data Leakage），为什么它会导致实验结果失去可信度？

- 训练集用来学习参数；验证集用来调超参数、选模型、做早停（训练过程中可以反复看）；测试集用来最终评估，理想情况下只看一次，不能拿它做任何决策。
- 数巨泄露是任何测试集或验证集的信息以某种形式进入了训练过程的情况。
- 评估的目的就是估计模型面对没见过的数据表现如何。一旦发生泄漏，模型在评估时其实已经见过答案，指标会虚高，这种虚高会让人误以为模型已经可用。

11.  正则化
什么是正则化（Regularization）？它主要用于解决什么问题？请简单说明 L1/L2 Regularization 和 Dropout 的基本思想。

- 正则化是通过给模型"加约束"来抑制过拟合、提升泛化能力的一类方法
- L1 Regularization：在损失里加上权重绝对值之和 λΣ|w|，因为|w|在 0 点不可导、梯度恒定，会把不重要的权重压到正好为0，产生稀疏解。
L2 Regularization：在损失里加上权重平方和 λΣw²，等价于每步都把权重往0拉一点。效果是让权重整体更小、模型更平滑，对单个特征不敏感，从而降低方差。
Dropout：训练时以概率 p 随机把一部分神经元的输出置零（并除以 1−p 保持期望不变），推理时全部保留。作用是打破神经元之间的"共适应"，迫使网络不依赖某几个固定神经元，效果类似同时训练很多子网络并做集成。

12.  数据标准化与归一化
为什么训练神经网络之前经常需要对输入数据进行标准化（Standardization）或归一化（Normalization）？它们之间有什么区别？数据尺度差异过大可能给训练带来什么问题？

- 如果神经网络的输入尺度差异很大，损失曲面会变成狭长的椭球：沿不同方向的梯度尺度差异巨大，梯度下降会在"陡"的方向来回震荡，只能靠很小的学习率慢慢挪，收敛极慢。统一尺度后，曲面更接近圆形，优化路径更直接，同时也能避免数值溢出、让激活函数工作在敏感区间。

| | Standardization（标准化 / Z-score） | Normalization（归一化 / Min-Max） |
| --- | --- | --- |
| 公式 | `(x − μ) / σ` | `(x − min) / (max − min)` |
| 结果 | 均值 0、方差 1 | 缩放到 [0, 1]（或 [-1, 1]） |
| 适合 | 近似正态分布、有离群点 | 有明确上下界的数据（如图像像素） |
| 缺点 | 受离群点影响（μ、σ 被拉偏） | 对离群点极其敏感（一个极值就压扁其余数据） |

13.  Batch Normalization
什么是 Batch Normalization？它通常放在神经网络的什么位置？为什么使用 BatchNorm 的模型在训练阶段和推理阶段需要采用不同的工作方式？

- 对每个 mini-batch，在特征维（通道）上计算均值和方差，把该维的取值归一化成均值0、方差1，再接一个可学习的缩放和平移γ·x̂ + β，让网络保留调整分布的能力。
- 通常结构为Linear/Conv → BatchNorm → 激活函数。
- 在训练阶段，用当前 batch 的统计量做归一化，同时用滑动平均把每个batch 的均值方差累积成一份全局统计量；在推理阶段：改用训练时累积的全局统计量，不再看当前batch。推理时可能只输入一条样本，单样本算不出有意义的方差；而且推理要求输出确定，即同一张图无论跟谁一起送进来，结果都应该一样。如果推理也用batch 统计量，结果就会随同批数据变化。

14.  分类模型的评价指标
Accuracy、Precision、Recall、F1-score 分别表示什么？在类别极度不平衡的数据集中，为什么只看 Accuracy 可能产生误导？什么情况下应该更加关注 Precision，什么情况下应该更加关注 Recall？

| 指标 | 公式 | 含义 |
| --- | --- | --- |
| Accuracy | (TP+TN)/(全部) | 总体判对了多少 |
| Precision | TP/(TP+FP) | 判为正的里面有多少真的是正（报的准不准） |
| Recall | TP/(TP+FN) | 真正的正例里有多少被找出来（有没有漏） |
| F1-score | 2·P·R/(P+R) | Precision 与 Recall 的调和平均 |

当类别极度不平衡时，比如假设1000条数据里只有10条是正例（1%），模型全猜反例，Accuracy 高达99%，但实际该模型无用。

- 更关注Precision：误报代价高时。
更关注 Recall：漏检代价高时。

15.  参数、超参数与模型泛化
什么是模型参数（Parameter），什么是超参数（Hyperparameter）？请分别举例。什么叫模型的泛化能力（Generalization Ability）？模型参数更多、网络更深是否一定意味着泛化能力更强？为什么？

- 参数是模型内部、由训练自动学出来的量。例如各层的权重矩阵和偏置、BatchNorm 的 γ/β、词嵌入表。
超参数是由人在训练前设定、训练过程不会自动改变的量。例如学习率、batch size、epoch 数、网络层数与隐藏维度、dropout 比例、优化器类型、正则化系数λ。

- 泛化能力是指模型在没见过的新数据上的表现。工程上一般看训练误差和验证误差的差距——差距小说明泛化好，训练误差远低于验证误差说明过拟合，两者都高说明欠拟合。
  
- 参数更多、网络更深时泛化不一定更强。原因：
①容量与数据的匹配。参数是容量的上限，但数据量不够时，容量越大越容易记住训练集噪声，泛化反而下降。
②优化难度。网络更深会遭遇梯度消失和网络退化，训练本身就更难，训练不好自然谈不上泛化。
③归纳偏置。合适的结构（比如图像用 CNN）比单纯堆参数更有效，此时结构本身编码了任务先验。
④正则化与训练策略。同样的参数量，不同的训练策略（数据增强、正则化、早停），泛化表现可能相差很多。
